# 🍔 Campus Bites – College Canteen Pre-Order System

Welcome to Campus Bites! A smart online food pre-ordering system designed for college students.

## 🏫 Our Canteens
- Block 2 Canteen
- Apple & Bees Canteen

## ✨ Features
- Browse food menus.
- View food images and prices.
- Select your preferred canteen.
- Add food items to cart.
- Place food orders in advance.
- Easy-to-use interface.

## 🎯 Project Objective
To reduce waiting time and make food ordering convenient for college students.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
